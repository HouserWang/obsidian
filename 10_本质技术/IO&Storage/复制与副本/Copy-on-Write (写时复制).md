# Copy-on-Write (写时复制)

### 📌 名词定义

Copy-on-Write (COW，写时复制) 是指**修改数据时，不直接覆盖原数据，而是创建新副本，最后替换引用。是实现无锁读取、快照隔离和数据一致性快照的关键技术。**

### 🧠 第一性原理

"读的时候不锁，写的时候才复制。"
读写锁会降低并发性能，如何让读操作完全无锁？
**本质策略：读操作共享同一份数据，写操作创建新副本，通过引用切换实现数据的原子更新。**

### 🛠️ 落地实现（典型应用）

```
Copy-on-Write 的核心应用：

1. Git 版本控制
   - 每次提交创建新的快照，不修改历史提交
   - 通过指针引用不同的快照
   - 支持快速回滚和历史查看

2. Docker 镜像
   - 镜像层是只读的，容器层是可写的
   - 修改文件时，从镜像层复制到容器层
   - 多个容器共享同一镜像层，节省空间

3. 数据库 MVCC
   - 读取时不加锁，读取数据的某个版本
   - 写入时创建新版本，不覆盖旧版本
   - 通过版本号实现快照隔离

4. Btrfs 文件系统
   - 快照功能：创建文件系统的快照，不复制数据
   - 修改时复制，保证快照的一致性

5. 核心优势
   - 无锁读：读操作完全无锁，性能极高
   - 快照隔离：支持多版本并发读取
   - 空间效率：多个版本共享未修改的数据
```

### ⚖️ 架构权衡

- **优点**：读操作无锁，性能极高；支持快照隔离和多版本并发；空间效率高。
    
- **缺点**：写操作需要创建副本，增加内存开销；频繁写时可能导致内存碎片。
    
- **大厂实践**：Git、Docker、数据库 MVCC、Btrfs 文件系统都通过 Copy-on-Write 实现高效的版本管理和并发控制。
