# Lamport Clock (逻辑时钟)

### 📌 名词定义

Lamport Clock（逻辑时钟）是指**一种简单的分布式时钟机制，通过传递事件编号，在分布式系统中建立"happened-before"的偏序关系，用于推断事件的因果顺序。它是向量时钟的基础，解决了"在没有全局时钟的情况下，如何判断事件先后"的问题。**

### 🧠 第一性原理

"事件之间有先后，但无法精确度量。"
分布式系统中物理时钟不可靠，但事件之间存在因果关系（A 发生在 B 之前）。
**本质洞察：通过事件编号的传递，建立偏序关系，但无法检测并发事件。**

### 🛠️ 落地实现（核心算法）

```
Lamport Clock 的核心机制：

1. 基本规则
   - 每个节点维护一个计数器 C
   - 每次发生事件，C = C + 1
   - 发送消息时，附带当前 C 值
   - 接收消息时，C = max(本地 C, 接收的 C) + 1

2. Happened-Before 关系
   - 如果 A → B（A 发生在 B 之前），则 C(A) < C(B)
   - 但反过来不成立：C(A) < C(B) 不能推出 A → B
   - 可能 A 和 B 是并发事件

3. 典型应用
   - 分布式日志排序：多个节点的日志按 Lamport 时间戳排序
   - 事件溯源：确定事件的因果顺序
   - 作为 [[Vector Clock (向量时钟)|Vector Clock]] 的基础

4. 局限性
   - 只能判断偏序（部分事件有先后关系）
   - 无法检测并发事件（C(A) < C(B) 但 A 和 B 可能无关）
   - Vector Clock 解决了这个问题，能检测并发
```

### ⚖️ 架构权衡

- **优点**：实现简单，开销极小（只需一个整数）；能建立事件的基本因果顺序。
    
- **缺点**：无法检测并发事件；只能判断偏序，不能判断全序。
    
- **大厂实践**：Lamport Clock 是分布式时钟的基础理论，Vector Clock 是其改进版本，广泛应用于 DynamoDB、Cassandra 等系统。
