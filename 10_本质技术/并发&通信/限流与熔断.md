# 限流与熔断 (Rate Limiting & Circuit Breaker)

## 📌 第一性原理

**保护系统，防止雪崩**：通过控制请求速率和快速失败，防止系统过载，保证核心服务可用。

---

## 🚦 限流 (Rate Limiting)

### 核心概念
限制单位时间内的请求数量，防止系统被突增流量打垮。

---

### 限流算法

#### 1. 固定窗口 (Fixed Window)
- **原理**：将时间分为固定窗口，每个窗口内限制请求数
- **优点**：实现简单
- **缺点**：窗口边界可能出现流量突刺（例如 0:59 和 1:01 各发 100 请求，实际 2 秒发了 200）
- **适用**：要求不高的场景

#### 2. 滑动窗口 (Sliding Window)
- **原理**：窗口随时间滑动，更精细地控制流量
- **优点**：无边界突刺问题
- **缺点**：实现稍复杂，存储更多状态
- **适用**：要求精确限流的场景

#### 3. 漏桶 (Leaky Bucket)
- **原理**：请求像水进入漏桶，桶满则丢弃，水以恒定速率流出
- **优点**：输出速率恒定，平滑流量
- **缺点**：突发流量会被丢弃
- **适用**：需要平滑输出的场景（如消息队列）

#### 4. 令牌桶 (Token Bucket)
- **原理**：以恒定速率向桶中放令牌，请求需要拿令牌才能通过
- **优点**：允许一定的突发流量（桶有剩余令牌时）
- **缺点**：实现稍复杂
- **适用**：大多数场景（Guava RateLimiter、Redis Cell）

---

### 限流策略

| 层级 | 说明 | 实现方式 |
|-----|------|---------|
| **网关层** | 统一入口限流 | Nginx、Kong、Spring Cloud Gateway |
| **应用层** | 单个服务限流 | Guava RateLimiter、Sentinel |
| **分布式限流** | 集群整体限流 | Redis + Lua、Sentinel 集群模式 |

---

## 🔌 熔断 (Circuit Breaker)

### 核心概念
当服务失败率超过阈值时，熔断器打开，后续请求快速失败，防止级联雪崩。

---

### 熔断器状态

#### 1. 关闭 (Closed)
- 正常状态，请求正常通过
- 统计失败率，若超过阈值则打开

#### 2. 打开 (Open)
- 快速失败，直接返回错误
- 等待超时时间后进入半打开状态

#### 3. 半打开 (Half-Open)
- 放行少量请求探测服务是否恢复
- 若成功则关闭熔断器，若失败则重新打开

---

### 熔断器实现

- **Hystrix**：Netflix 开源，已进入维护模式
- **Resilience4j**：轻量级，Java 8+ 函数式编程
- **Sentinel**：阿里巴巴开源，功能强大（限流+熔断+降级）

---

## 🎯 降级 (Degradation)

### 核心概念
当系统压力大时，关闭非核心功能，保证核心功能可用。

### 降级策略
- **页面降级**：静态页面替代动态页面
- **服务降级**：返回默认值或缓存数据
- **功能降级**：关闭非必要功能（如评论、推荐）

---

## 🛡️ 高可用三板斧

| 技术 | 作用 | 场景 |
|-----|------|------|
| **限流** | 控制流量 | 突增流量、防止过载 |
| **熔断** | 快速失败 | 依赖服务故障、防止雪崩 |
| **降级** | 丢卒保车 | 系统压力大、保证核心 |

## 🏗️ 实际应用

### Spring Cloud Gateway 限流
```yaml
spring:
  cloud:
    gateway:
      routes:
      - id: limit_route
        uri: http://localhost:8080
        predicates:
        - Path=/api/**
        filters:
        - name: RequestRateLimiter
          args:
            redis-rate-limiter.replenishRate: 10
            redis-rate-limiter.burstCapacity: 20
```

### Sentinel 限流熔断
```java
@SentinelResource(
    value = "resource",
    blockHandler = "handleBlock",
    fallback = "handleFallback"
)
public String doSomething() {
    // 业务逻辑
}
```
